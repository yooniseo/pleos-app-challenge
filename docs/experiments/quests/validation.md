## 확인한 동작

- **같은 교차로**에서 우회전 준비 차로 변경 → 우회전 → 교차로 출구의 세 상황을 전달.
- 단순 관측값·안내 제공만으로 경험이나 퀘스트를 완료하지 않음.
- 우회전과 같은 교차로 출구를 묶어 교차로 경험 한 번만 기록.
- 상황 ID·발생 ID·출처·확인 근거 불일치 및 중복 수행을 거절.
- 취소·건너뜀·미확인·보류는 보상이나 실패 판정 없이 다음 상황으로 진행.
- 어려움 메모가 확인된 경험을 차감하지 않음.
- 네 단계 퀘스트를 순서대로 완료하고 명시적으로 코칭을 줄인 뒤 복구 가능.
- 차로 변경을 간략히로 바꾸면 같은 설정이 주행 코치 포트로 전달됨.
- 서로 다른 어댑터 인스턴스에서도 설정 변경 구독이 반영됨.
- JSON 저장/읽기 및 Activity 재시작 후 단계·설정 복원, 개인/시연 기록 분리.
- 다음 목표는 현재 주행 복습 후 예약하고 다음 주행의 집중 목표로 반영.
- 많은 관측 이벤트가 들어와도 수행 확인을 처리하며 사건 로그는 최근 500개로 제한.

## 검증하지 않은 것

- 실제 Pleos 에뮬레이터·실차의 NaviHelper/Vehicle 값 수신, 권한, 서비스 연결.
- 실제 차량 이동 중의 UX 제한 콜백. 보호 코드는 컴파일했으며 일반 Android 에뮬레이터에서는 Automotive 분기를 실행하지 않음.
- 실제 음성 인식·재생, 센서 기반 차로 변경·우회전·출구 판단. 이번 구현은 1번의 연결 인터페이스만 제공함.
- 회고 담당자의 별도 브랜치와 실제 병합·통합. 해당 인터페이스만 검증함.
- 제출용 release 서명·공모전 심사 적합성.

실행용 산출물은 debug APK이며 제출용 release APK가 아닙니다. `main` 또는 기존 `MainActivity.kt`를 수정하거나 다른 팀 브랜치를 병합하지 않았습니다.
