# 아이디어와 실험 기록

튜토리얼의 기능은 아직 확정되지 않았습니다. 이 폴더는 세 팀이 아이디어와 실험 결과를 공유하기 위한 공간입니다.

| 내용 | 위치 |
| --- | --- |
| 앱 실행과 현재 시작 프로젝트의 구현 범위 | [프로젝트 README](../README.md) |
| 팀별 scratch 브랜치 운영과 파일 규칙 | [실험 브랜치 운영 규칙](../CONTRIBUTING.md) |
| 아이디어와 실험 결과를 남길 양식 | [실험 기록 양식](experiments/template.md) |
| 기존 기획 논의 참고 | [Notion 페이지](https://app.notion.com/p/40ec764e469380dd8359f23473e39d06) |

기존 기획 자료에 있는 기능·우선순위·번호는 확정 요구사항으로 취급하지 않습니다. 지금 단계에서는 요구사항 명세를 새로 작성하지 않습니다.

퀘스트 팀은 `experiments/quests/`, 주행안내 팀은 `experiments/driving-guide/`, 주행이후 팀은 `experiments/post-drive/`에 첫 기록을 만들 때 폴더를 추가합니다. 파일 이름은 `2026-11-04-voice-coach.md`처럼 날짜와 주제로 작성합니다.

팀은 실험을 계속 바꾸거나 보류할 수 있습니다. 관찰한 결과와 아직 확인하지 못한 내용을 구분해 남겨주세요.
