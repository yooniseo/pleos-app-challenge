# 프로젝트 문서

팀 뿌까의 튜토리얼 프로젝트에서 개발 중 참고할 문서를 두는 위치입니다.

| 내용 | 위치 |
| --- | --- |
| 앱 실행과 현재 구현 범위 | [프로젝트 README](../README.md) |
| 파일·폴더 이름과 Git 협업 규칙 | [팀 개발 규칙](../CONTRIBUTING.md) |
| 기능 기획과 요구사항 | [Notion 요구사항 정의 및 명세서](https://app.notion.com/p/40ec764e469380dd8359f23473e39d06) |
| 코드와 변경 이력 | [GitHub 저장소](https://github.com/yooniseo/pleos-app-challenge) |

## 문서를 추가할 때

- 개발 설명은 `vehicle-sdk-notes.md`처럼 주제를 알 수 있는 영문 이름으로 작성합니다.
- 회의록은 `2026-11-04-guidance-priority.md`처럼 날짜와 주제를 붙입니다.
- 문서용 캡처는 필요한 시점에 `docs/images/`에 추가하고 문서에서 상대 경로로 연결합니다.
- 회의에서 결정한 내용과 검토 중인 제안을 구분합니다. 아직 구현하지 않은 기획을 앱 기능으로 소개하지 않습니다.
- 문서가 늘어나면 위 표에 링크를 추가합니다. 파일을 옮기거나 이름을 바꾸면 관련 링크도 수정합니다.
