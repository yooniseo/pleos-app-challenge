# 조건부 코칭과 조향 시연 검증

지도 화면의 깜빡이 OFF, 오른쪽 ON, SDK 입력으로 코칭 입력을 고른다. 비교 안내 듣기는 현재 연습을 일시정지하고 우회전 준비 문장을 재생한다. 자동 시연을 시작하면 선택한 입력을 차선 변경 준비와 우회전 준비에도 적용한다.

| 입력 | 우회전 준비 문장 |
| --- | --- |
| OFF | 오른쪽 깜빡이를 켜고, 우회전 전 횡단보도도 살펴보세요 |
| RIGHT | 우회전 전, 횡단보도도 살펴보세요 |
| LEFT | 오른쪽 깜빡이로 바꾸고, 우회전 전 횡단보도도 살펴보세요 |
| UNKNOWN | 깜빡이 상태를 확인하고, 우회전 전 횡단보도도 살펴보세요 |

시연 버튼 입력은 차량 쓰기 API를 호출하지 않는다. SDK 입력은 기존 PleosCoachSource의 읽기 결과를 사용한다. 구독 실패나 오래된 값은 UNKNOWN으로 처리한다. ON/OFF 버튼을 눌러도 이미 재생된 자동 안내를 반복하지 않는다. 두 문장을 다시 비교할 때는 비교 안내 듣기를 누르거나 새 연습을 시작한다.

차선 변경의 오른쪽 조향, 반대 조향, 가운데 복원을 구분한다. 주차도 후진하며 오른쪽 조향, 왼쪽 조향, 최종 정렬을 구분한다. 핸들 위치는 가상 경로의 곡률로 계산하고 핸들 화살표는 제거했다. 화면과 음성이 현재 시연 핸들에서 더 돌릴 방향과 풀 방향을 알려준다. 핸들에만 적용하던 시간 지연을 제거했다. 주차 화면의 차량 위치와 방향도 지도와 같은 시연 좌표를 사용한다.

초보자가 안내를 듣고 다음 동작을 예상하도록 도로 재생 속도는 8/6km/h, 주차는 3/2km/h로 설정했다. 주차 주변 확인은 5초 정차한다. 우회전 조향 문장은 회전 시작 3m 앞에서 시작한다. 화면 문구와 음성은 같은 단계에서 생성한다. 음성은 조향·복원 구간마다 한 번 요청하며 이전 음성이 끝난 뒤 현재 유효한 안내만 요청한다.

조향 모델은 축거 2.7m, 조향비 14.5를 가정한 시연이다. 이 가정은 차종별 검증을 거치지 않았다. 지도상의 차로와 횡단보도 위치도 교육용 가상 표시다. 실제 서비스에는 차량 조향각, 위치 정확도와 차로 판단, 차량별 보정, 보행자·신호 정보의 수신 가능 범위 검증이 필요하다. 실제 사용자가 문장을 듣고 반응하는 시간은 사용자 테스트로 추가 검증해야 한다.

조향 방향 검증의 수학적 기준은 속도와 조향각으로 차체 방향 변화율을 구하는 bicycle kinematics를 참고했다. 후진 시 속도의 부호가 바뀌는 점을 반영한다. [MathWorks 모델 문서](https://www.mathworks.com/help/robotics/ug/mobile-robot-kinematics-equations.html)

검증은 독립된 product-validation.db에서 실행한다. 네 연습의 완료 기록, 보상, 퀘스트 저장과 재시작 후 조회를 확인한다. real_time=true 계측 실행은 네 연습을 실제 재생 시간으로 진행하고 단계별 화면, 차량 방향, 핸들 값, 문구, 음성 요청과 SDK 재생 콜백을 proof.json에 기록한다.

같은 회전 안에서도 여러 번 더 돌리고 풀어야 하면 새 구간에서 안내한다. 화면에서는 그림처럼 오른쪽/왼쪽으로 더 돌리기, 반대 방향으로 풀어 가운데로 맞추기, 현재 위치 유지, 가운데 유지를 구분한다. 음성 문장은 화면 지시의 방향을 유지하면서 짧게 제공한다.

최종 APK에는 한 바퀴 돌아간 핸들과 가운데 위치를 구분하는 현재 시연 핸들 상태 표시도 포함한다. focused_real=true 검사는 연결 시연/첫 차선 변경을 가상 시간으로 완주하고, 우회전/주차/탭 전환 차선 변경은 실제 시간으로 재생한다. 이 모드도 각 시나리오의 DB 완료·보상·재조회 검사를 수행한다.
