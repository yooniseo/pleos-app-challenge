Figma `Sqpacf0pJmLc2RNnZBUrqo`의 `42:5211` 구역은 배치·색·정보 계층을 참고하는 시각 자료다. 사용자의 최종 지시에 따라 Figma에서 내려받은 이미지/SVG를 앱에 사용하지 않는다. 파일은 읽기만 했으며 원본 디자인 노드는 수정하지 않았다.

모든 새 그림은 `ui/ProductIllustrations.kt`의 Android Canvas 벡터 도형·레이어·그라데이션으로 만든다. 화면 해상도에 맞춰 그리며 차량 위치/방향·핸들 회전·진행률은 세션 상태와 연결한다. 사진이나 UI 스크린샷을 붙인 화면이 아니다. Figma에서 다운로드했던 에셋과 AndroidSVG 의존성은 제거했다.

핸들은 이전 코칭 구현을 `SteeringWheelRenderer`로 분리해 유지했다. 회전하는 스포크·상단 표식·희미한 직진 기준·복원을 보여주며, 주차에서도 전체가 보이도록 했다. 수동 페달·기어·차량 물리 조작은 복원하지 않았다.

글꼴은 기존 Asta Sans를 유지한다. OEM Driving View·상태표시줄·하단 공조/GNB는 앱에서 복제하지 않는다. 도로 중심선은 실제 OSM 데이터이고 차로/횡단보도/조향은 교육용 시연 표현이다.
