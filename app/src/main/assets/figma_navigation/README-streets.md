# 경기대 후문 짧은 주행 시나리오

- 지도: OpenStreetMap 도로 중심선·건물/녹지 형상 39개 도로, 128개 구역을 오프라인으로 표시합니다.
- 출처: https://www.openstreetmap.org/api/0.6/map?bbox=127.0395,37.294,127.045,37.301 (2026-11-12).
- OSM 유래 데이터 `kgu-streets.json`은 [ODbL](https://opendatacommons.org/licenses/odbl/1-0/)에 따릅니다. 저작자: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). 이 데이터 라이선스는 앱 소스의 라이선스와 별개입니다.
- `scripts/build-teaching-map.py`로 XML extract에서 재생성할 수 있습니다.
- 경로는 기존 `kgu-route.json`의 OSRM 도로 중심선을 사용합니다. 실제 차로 수준의 지도/경로 데이터가 아닙니다.
- 차로 폭·차선 경계는 교육용 표현이며, 차로 수 태그가 없는 곳은 기본값을 사용합니다. 횡단보도 두 곳은 교육용 가상 배치로 실제 위치를 검증하지 않았습니다. 도로 형상이 실제 데이터라는 이유로 차로/횡단보도까지 실측이라고 해석하면 안 됩니다.
- 마커: 기존 Figma 내비게이션 PNG. 아이콘·폰트·라이선스는 기존 에셋을 재사용합니다.

## 실행

기본: `연습 시작` → 2차로에서 3차로로 한 번 이동 → 대학로 방향 우회전 → 퀘스트 2/2.
시나리오 선택에서 차로 변경만 / 우회전만 선택할 수도 있습니다.

- 자동 재생: 직진 20km/h, 회전 12km/h. 지도 내부 모델만 움직이고 Virtual Console은 P·0을 유지합니다.
- 차량 SDK: `SpeedSource`의 실제 AAOS `PERF_VEHICLE_SPEED` (m/s)를 시간 적분합니다. Console 쓰기 브리지를 정리한 뒤 읽기만 수행합니다. 속도 0, 값 없음/5초 이상 응답 없음, 비정상 값에서는 정지합니다. 앱 중단/1초 이상 프레임 지연 구간은 외삽하지 않습니다.
- 두 모드 모두 위치·차로는 시나리오 값입니다. GPS 추적, 현재 물리 차로 감지, 실차 차로 변경 성공 판정은 아닙니다.
- 퀘스트는 시나리오 이벤트(진입 → 안내 → 동작 완료)로 연결합니다. 차로 변경은 42m 지점, 우회전은 경로 끝에서 완료합니다. SDK 속도/깜빡이 콜백 자체로는 완료하지 않습니다. 두 모드 모두 SIMULATION 기록으로 저장하며 개인 기록을 변경하지 않습니다.
- 공통 DB/Room 통합은 이 변경의 범위에 포함하지 않습니다. 현재 퀘스트 저장소는 기존 SharedPreferences 어댑터를 사용합니다.
- 주행 피드백에는 완료 항목, 이동 거리, 속도 출처, 순간 메모를 표시하고 마지막 보고서를 보관합니다.

## 검증

`navigation_probe=1` native instrumentation: 자동 시나리오 끝까지 실행, 일시정지 위치 고정, 퀘스트 2개 추가, 개인 데이터 유지, 자동 재생 실제 SDK 속도 0, 차량 SDK 20km/h 입력의 약 4초 거리 적분, 외부 Console 입력 소유권 유지, 종료 후 P·0 복원.
기존 수동 운전석과 긴 자동 시연은 `운전 조작`에서 계속 사용할 수 있습니다.

## 초보자 코치와 차량 상호작용

- `나의 코치`에서 차근차근(확인 순서/이유), 핸들 중심(방향/회전량/복원), 짧게(지금 할 일)를 선택하며 기기에 저장합니다. 선택한 방식은 지도 카드와 TTS 문구에 반영합니다. 운전자 식별·AI 분석·gain DB 연동을 구현한 것은 아닙니다.
- 핸들 그림은 기존 native `SimulatorWheelView`를 읽기 전용으로 재사용합니다. 핸들 애니메이션의 내부 각도는 경로 곡률과 가상 휠베이스 2.7m/조향비 14.5로 계산합니다. 사용자에게는 각도 숫자를 표시/낭독하지 않고 살짝·1/4 바퀴·반 바퀴·한 바퀴 같은 회전량으로 안내합니다. 실제 차종별 조작 지시가 아닙니다. 차로 변경의 진입·복원 및 회전에 따라 변합니다. 조향 장치를 제어하지 않습니다.
- 퀘스트가 새로 완료되면 짧은 앱 자체 축하 멜로디와 화면 테두리 효과를 재생합니다. `quest_success.wav`는 C5–E5–G5–C6를 코드로 합성한 자체 음원이며 외부 음악 앱을 조작하지 않습니다. 기기 음량/오디오 포커스에 따릅니다.
- Pleos `Vehicle` SDK의 ambient-light capabilities/권한을 확인하고, 실제 속도 값이 0이며 P단일 때만 민트색 펄스를 요청합니다. 1.2초 뒤 원래 색을 복원하며 화면 종료 시에도 복원합니다. 주행 중이면 조명은 정차 후로 미룹니다. 미지원이면 지원하지 않는다고 표시합니다. 성공은 SDK 색상 응답과 복원 응답으로 검증합니다.
- 추가 `후진 주차 · 가상 연습장`은 실제 경기대 주차장 지도를 주장하지 않는 별도 연습장입니다. 전진 위치 맞춤 → 2초 정차/주변 확인 단계 → R단 모형 후진 → 차체 정렬 → 가상 P단으로 종료합니다. 실제 기어는 P·0 유지, 전진 3km/h/후진 2km/h 모형입니다. 주변 확인 단계는 시나리오 표현이며 실제 주변 안전을 감지하지 않습니다. 퀘스트는 PARKING 이벤트로 1회 기록합니다.

- 핸들 안내는 진입/복원 시점을 구분합니다. 차로 정렬 시 가운데로 풀기, 주차 최종 직선 후진 구간에서 빠르게 풀기를 안내합니다. TTS는 분수 표기를 자연어로 바꾸고 최소 간격을 두어 매 프레임 반복하지 않습니다.

## 차근차근 앱 실행 / 핸들 따라하기

- 앱 이름은 `차근차근`입니다. 개발용 화면 3개의 런처 등록을 하나로 합쳤습니다. Pleos 앱 목록에서 `차근차근`을 누르면 개발용 에뮬레이터에서 지도·핸들·퀘스트 코치가 바로 열립니다. 기존 Main/Quest Activity는 내부 화면으로 유지합니다. Simulator exported/DO 설정을 확대하지 않습니다.
- 반 바퀴 이하의 코칭은 수치를 읽지 않고 `핸들을 오른쪽/왼쪽으로 꺾으세요`라고 안내합니다. 그보다 큰 회전에서는 한 바퀴 등의 양을 안내하고 정렬 시 복원을 알려줍니다.
- `따라하기`를 누르면 지도를 잠시 멈추고 마우스로 핸들을 돌릴 수 있습니다. 현재 경로 목표가 작은 경우 준비 동작으로 오른쪽 꺾기(주차는 한 바퀴)를 연습합니다. 연한 핸들이 목표, 진한 핸들이 직접 입력한 위치입니다.
- 실제 드래그 입력이 목표 허용 범위에 350ms 유지되면 `steering_ding.wav`를 한 번 재생합니다. 잘못된 방향/자동 애니메이션/입력 없음으로는 성공하지 않습니다. 한 번 성공한 시도에서 중복 재생하지 않습니다. 이 성공은 가상 핸들 입력 평가이며 실제 차량 조향 성공으로 보거나 주행 퀘스트를 완료하지 않습니다.
- `연습 마치기`로 이전 일시정지 상태를 복원합니다. 핸들 따라하기 결과는 순간 메모에 기록합니다. 효과음은 앱 자체 합성 음원이며 축하음 설정을 따릅니다.
- `interaction_probe=1` native instrumentation은 실제 런처 Intent, 아이콘 1개/이름, 오른쪽 핸들 목표에 잘못/올바른 드래그 이벤트 주입, 띵동 1회, 부당한 퀘스트 증가 없음, 설명 방식 선택, 가상 시간으로 주차 완료 및 퀘스트 저장을 검사합니다. 주차 가상 시간 검사는 실시간 시연 속도를 측정하는 검사가 아닙니다.
